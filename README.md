# AI-Mask-detector
😷 AI-powered face mask detection system built with CNN (TensorFlow/Keras). Upload an image and instantly detect whether a person is wearing a surgical mask or not. Trained on a custom dataset with 800+ images.
# 😷 Mask Detection Web App

## Features
- Upload Image
- Detect Mask / No Mask
- Color Output

## Run
pip install -r requirements.txt
python app.py
